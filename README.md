- Linux und Systemadministration

Aufbau praktischer Kenntnisse in modernen Infrastruktur-Technologien und deren Einsatz in Cloud- und Enterprise-Umgebungen.

Dieses Repository dokumentiert meinen Lernfortschritt, praktische Übungen und technische Notizen.

## Lernansatz

Im Rahmen der Beschäftigung mit Docker wurde deutlich, dass für ein tieferes Verständnis der systemintegratorischen Zusammenhänge auch grundlegende Kenntnisse der Webentwicklung notwendig sind.

Daher wird eine kleine Flask-Webanwendung Schritt für Schritt weiterentwickelt. Dabei steht nicht die Softwareentwicklung im Vordergrund, sondern das Verständnis der technischen Zusammenhänge:

- Wie kommunizieren Anwendung und Datenbank?
- Wie werden Daten verarbeitet und dargestellt?
- Welche Aufgaben übernehmen Python, Flask, Jinja, HTML und SQL?
- Wo liegen die Verantwortlichkeiten der einzelnen Komponenten?
- Wie lässt sich bestehender oder KI-generierter Code nachvollziehen und sinnvoll  beurteilen?

Die Webanwendung dient damit als praktische Lernumgebung, um Programmier- und Codeverständnis aufzubauen und gleichzeitig systemintegratorische Zusammenhänge sichtbar zu machen.

## Aktueller Stand

Die Webanwendung basiert auf Flask und SQLite. Daten werden aus der Datenbank gelesen und über Jinja in einer HTML-Oberfläche dargestellt.

Aktuell werden unter anderem:

- Aufgaben aus der Datenbank ausgelesen
- Statuswerte benutzerfreundlich dargestellt
- Prioritäten übersetzt
- optionale Deadlines angezeigt

Die Anwendung wird bewusst in kleinen, nachvollziehbaren Schritten erweitert. Neue Technologien werden erst dann eingeführt, wenn die grundlegenden Zusammenhänge verstanden und praktisch erprobt wurden.
